越小越低延迟，但网络抖动时更容易断流。唱歌建议 30–50ms。

怎么让音乐软件把它当成麦克风

1. 安装 VB-Audio Virtual Cable（免费），重启后系统里会多出 CABLE Input 和 CABLE Output。

2. 在上面的"播放到哪个设备"里选 CABLE Input。

3. 在微信 / OBS / 音乐软件里，把麦克风选成 CABLE Output。

4. 唱歌时请用耳机听伴奏，用外放容易啸叫。

不想装任何驱动？三种零安装用法

① 会议 / 网课 / 语音聊天
上面的"播放到哪个设备"保持 系统默认输出，在会议软件里把麦克风选成 立体声混音（有些驱动叫 Stereo Mix / What U Hear）。
注意：它会把电脑正在播的所有声音一起送过去。想避免对方听到自己说话，请把会议软件的声音输出到 另一块声卡（USB 耳机或 HDMI 显示器），或者在会议软件里开启回声消除。

② 直播 / OBS
不用虚拟声卡。OBS 里添加「应用程序音频采集」，目标选运行接收页的浏览器（Chrome/Edge）， 就只会把这路手机声音送进直播。也可以直接添加"浏览器源"打开接收页并勾选控制音频。

③ 只想录一段人声
点上面的"录制为 WAV"，接收到的原始 PCM 会直接存成 16bit/48kHz 单声道 WAV， 再拖进任何录音软件或剪辑软件即可。不受缓冲、断流影响。

唱歌 / 乐器 / 需要"只录手机"的场合仍然需要虚拟声卡： Windows 自带没有任何虚拟录音设备，立体声混音会把伴奏一起录进去，蓝牙免提只有 16kHz。
